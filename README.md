# Qubic Wallet trust, source and comparisons

Eleven guides for the question behind the download: is this wallet what it says it is, and how would
you check without taking anyone's word for it.

Start with [what Qubic Wallet is](what-is-qubic-wallet.md), then continue into the safety page for the
evidence rather than the verdict.

Nothing here claims an audit or an endorsement. The guides point at the release, the repository and
the seed model, and say plainly where a claim cannot be verified from those alone.

Comparisons with the web wallet, hardware wallets and cold storage are included, along with the
October 2026 weak-seed incident and what it did and did not affect.
